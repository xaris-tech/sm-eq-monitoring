# Comms reference photos

Photos shown next to each item on the Comms Checklist, so volunteers can see what a part looks like.

1. Photograph the church's own gear on a plain background, one item per photo.
2. Resize to about 800px wide and save as JPEG at roughly 100KB.
3. Name the file after the item: `COMMS-BASE-01.jpg`, `COMMS-ANTENNA-01.jpg`, … plus `BELTPACK.jpg` and `HEADSET.jpg`. In-ear monitors are personal equipment, so they have no photo.
4. Put it in this folder and set its path in `COMMS_PHOTOS` in `js/config.js`, e.g. `'COMMS-BASE-01': 'img/comms/COMMS-BASE-01.jpg'`.

Items without a photo show "No photo yet".
